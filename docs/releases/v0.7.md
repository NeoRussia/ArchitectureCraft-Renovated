A shape release. Window glazing takes any pane and stops reading as its frame
under a shader pack, a corner pillar joins the sawbench, and the walls and fences
are repriced.

Fixes
-----
- **Window glazing takes any pane.** Any glass that is not a full cube counts, so
  modded panes and Chisel's variants work instead of being refused by block
  identity.
- **Glazing no longer reads as its frame.** Under a shader pack each face reports
  the material it was drawn from, so glass faces pass light; cutout glass is
  looked up per state like translucent glass.

Additions
---------
- **Corner Pillar, ID 150.** A quarter column whose long axis follows the face it
  is placed against. Shift lays it on the picked face, along the edge clockwise
  from the aimed corner. One material block makes four, and a piece placed beside
  another takes its direction and paintbrush turn.
- **Russian is complete.** The four pages and every shape name that had no
  translation now have one.

Changes
-------
- Walls and fences cost three material blocks to make four, matching the stairs.
- The paintbrush is now the Architect's Paintbrush, in step with the chisel and
  the hammer.

Requirements and install
------------------------
- Minecraft 1.12.2, Forge 14.23.4.2747, the version it is built against; the
  14.23.5 line works too. Java 8, and Cleanroom 0.7.x.
- No required dependencies. The One Probe support appears once it is installed.
  The shader block ids need Demonica, and do nothing without it or with shaders
  switched off.
- Drop the jar into `mods/` and start the game. Existing worlds keep their shapes
  and their orientation.

Known limitations
-----------------
- **At Distant Horizons distance every shape is stone.** Its LODs are keyed on the
  block state and a shape's material is in the tile entity. Add
  `architecturecraft:shape` to `ignoredRenderBlockCsv` in `DistantHorizons.toml`
  if you would rather have them absent.
