A shape release: a walrus that keeps its own eyes, a glowing panel and a ramp
that completes the round inner corner, plus a sawbench that always shows the
result it would really give.

Additions
---------
- **Walrus, ID 153.** ExtraCells2's walrus, two blocks long and cut from one
  material block. It is placed with its head towards you and its body lying
  away, whichever face you click. The body takes the material, repeating once
  per block so the texels match the blocks around it; the eye, whiskers and
  tusks keep the model's own artwork. One whole-cell collision box, so the
  overhanging tail is neither clickable nor collidable. Model and skin are
  ExtraCells2's (MIT); see `CREDITS.md`.
- **Glow Paneling, ID 152.** The paneling shape with the Glow page's light,
  placed right of the glowing slab.
- **Round Inner Corner Ramp, ID 151.** The inner corner's quarter-round as an
  incline, so a curved corner can climb. Both arcs shade smoothly rather than in
  bands.

Fixes
-----
- **The sawbench always shows the result it would give.** It rebuilt the result
  only when the slot was set through the GUI, so growing a stack by right-click
  and drag, or a bench restored from disk, could show a result the server would
  not honour. It now rebuilds on any slot change and on load, and a craft that
  took no material is closed.
- **Shift-click reaches every slot.** The last two inventory slots were outside
  the merge range.
- **Thin shapes no longer cast a full block's shadow.** Light lost is measured
  from the mesh, not from the collision boxes, and the round inner corner has a
  hitbox that follows its lens. That also removed the dark band where two
  pieces meet.

Changes
-------
- Model shapes measure their own volume for the light tier.
- A shape can carry a description line in its tooltip; the walrus has one.

Requirements and install
------------------------
- Minecraft 1.12.2, Forge 14.23.4.2747, the version it is built against; the
  14.23.5 line works too. Java 8, and Cleanroom 0.7.x.
- No required dependencies. The One Probe support appears once it is installed.
  The shader block ids need Demonica, and do nothing without it or with shaders
  switched off.
- Drop the jar into `mods/` and start the game. Existing worlds keep their shapes
  and their orientation.

Known limitations
-----------------
- **At Distant Horizons distance every shape is stone.** Its LODs are keyed on the
  block state and a shape's material is in the tile entity. Add
  `architecturecraft:shape` to `ignoredRenderBlockCsv` in `DistantHorizons.toml`
  if you would rather have them absent.
- **The walrus hangs over its block.** The block holds the head and shoulders and
  the body lies in the next cell, so a wall behind it will clip the tail; the
  collision box stays inside its own block.
