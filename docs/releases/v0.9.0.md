A small shape release: a cladding corner pillar, a Double Roof Tile that costs
what it looks like it costs, and a sawbench that converts a whole stack in one
shift-click again.

Additions
---------
- **Cladding Corner Pillar, ID 154.** A full block whose north-west quarter
  column (0.5 x 1 x 0.5, the Corner Pillar's quarter) is the cladding material,
  flush with the block. Until a cladding is applied the quarter is simply more of
  the block, so the shape doubles as a plain cube; apply a cladding and the
  corner turns into that material on every face. Placement is the Corner
  Pillar's: upright on a floor or ceiling, along the wall's normal on a wall, the
  aimed corner picks the edge, sneaking lays it down, and a piece placed against
  another copies its direction. One block makes one.

Fixes
-----
- **A shift-click on the sawbench output converts the whole stack again.** The
  result slot refills as soon as it is emptied, which is exactly what makes
  vanilla repeat a shift-transfer; the container reported the move in a way that
  stopped that repeat, so one click gave one piece. It now converts until the
  material or the inventory runs out.
- **Nothing else can be pushed into the sawbench output.** A stack equal to the
  current result could land in the output slot through the same transfer path,
  because the merge skips the slot's own validity check when topping up a
  matching stack. Player stacks now go to the material slot only.
- **Shape 151 reads "Round Inner Corner Ramp"** in game, as the release notes
  always had it.

Changes
-------
- Double Roof Tile is one block for one, matching the other full-block shapes;
  it was one for two.

Requirements and install
------------------------
- Minecraft 1.12.2, Forge 14.23.4.2747, the version it is built against; the
  14.23.5 line works too. Java 8, and Cleanroom 0.7.x.
- No required dependencies. The One Probe support appears once it is installed.
  The shader block ids need Demonica, and do nothing without it or with shaders
  switched off.
- Drop the jar into `mods/` and start the game. Existing worlds keep their shapes
  and their orientation.

Known limitations
-----------------
- **At Distant Horizons distance every shape is stone.** Its LODs are keyed on the
  block state and a shape's material is in the tile entity. Add
  `architecturecraft:shape` to `ignoredRenderBlockCsv` in `DistantHorizons.toml`
  if you would rather have them absent.
